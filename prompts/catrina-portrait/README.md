# Catrina Portrait Generator

Hyper-realistic 9:16 vertical Día de Muertos portraits with Catrina face paint, marigold crowns, and festive Mexican altar scenery.

**Generator:** ChatGPT · **Status:** Active

---

## The Prompt

```
Hyper-realistic 9:16 vertical scene. Identity preserved exactly — face, expression, posture, body proportions from the reference photo unchanged.

Catrina face paint (white base, black accents, crimson red), marigold flower crown, sitting on purple sheets. Surroundings: candles, pan de muerto, sugar skulls, skeleton companion, horror movie posters, papel picado.

Warm cinematic neon lighting (orange and amber), 50mm lens, medium depth of field, ultra-detailed textures, cinematic glow.
```

## Variations

- Change the holiday theme (Halloween, Carnival, Christmas posada)
- Swap the bed colors and sheet style
- Adjust the makeup intensity (full Catrina, subtle sugar skull, bare face)
- Change the background decorations (altar, ofrenda, street celebration)
