```

Orange loose-neck knitted sweater, wine-red pleated short skirt, matching thigh-high stockings, shiny wine-red Mary Janes with thick soles.

Background: abandoned mansion library with cobwebs, busts, chandelier, furniture covered in sheets. Moonlight through windows creating an eerie atmosphere.

Do not alter facial or body features.
```
