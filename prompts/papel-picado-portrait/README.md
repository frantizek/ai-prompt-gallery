# Papel Picado Portrait Generator

Transform portraits into Mexican papel picado designs cut from gold metallic paper with delicate perforations, floral motifs, and symmetrical patterns.

**Generator:** ChatGPT · **Status:** Active

---

## The Prompt

```
Transform this image into a Mexican papel picado design made entirely from gold metallic paper. Use the shapes and silhouettes from the original image to create the cutout pattern itself, as if the image were hand-cut into the paper.

Include delicate perforations, floral and geometric motifs, and symmetrical patterns. A single sheet of golden tissue paper, intricately cut, with the main image's outlines forming the central motif.

Style: handcrafted, Mexican folk art, detailed perforations, elegant, symmetrical.
Material: thin metallic gold paper with soft reflections.
Background: white or transparent.
Quality: ultra-detailed, realistic texture, crisp vector-like edges.
```
