# Geometric Broken Realism Portrait Generator

GBR portraits constructed from fragmented geometric brushstrokes, sharp polygon shapes, and layered abstract blocks with soft paint textures.

**Generator:** ChatGPT · **Status:** Active

## The Prompt

Copy this and attach a reference photo:

```
Create a striking GBR (Geometric Broken Realism) portrait based on the attached reference photo. The face is constructed from fragmented geometric brushstrokes, sharp polygon shapes, and layered abstract blocks. Use expressive, fragmented edges with dynamic overlay, combining soft paint textures with hard, angular forms.

Emphasize facial structure through color segmentation rather than contouring. Apply a soft yet rich color palette of warm skin tones. Add fine sketch lines and a touch of digital painting to enhance depth and movement.

The background is clean, minimalist, making the fragmented portrait stand out. The lighting is soft and diffused, creating modern artistic illustrations with a bold, editorial feel.

High-resolution contemporary digital art with expressive and highly detailed cinematic composition.
```

## Variations

- Adjust the fragmentation level (subtle cracks, fully shattered)
- Change the color palette (cool tones, monochrome, neon accents)
- Swap the background color (white, black, muted pastel)
- Change the brushstroke style (oil paint, charcoal, digital airbrush)
