# Forced Perspective Portrait Generator

Playful outdoor scenes using forced perspective to create humorous illusions — pinching, lifting, or interacting with miniature background figures.

**Generator:** ChatGPT · **Status:** Active

## The Prompt

Copy this and customize the subjects and setting:

```
A playful forced-perspective outdoor scene in an open green field under a cloudy sky. A young man in a light grey sweater stands in the foreground, smiling, with his arm extended as if he is pinching and lifting a miniature version of another man in the distance. The background figure appears tiny due to perspective, balancing on one leg with arms spread wide, creating a humorous illusion. The environment features soft natural lighting, scattered bare trees on the horizon, and a peaceful rural atmosphere. Ultra-realistic photography style with sharp detail, natural colors, and a fun surreal twist.
```

## Variations

- Change the interaction (holding between fingers, stepping on, flicking)
- Swap the setting (beach, city sidewalk, mountain trail)
- Change the outfits (formal, beachwear, winter coats)
- Adjust the perspective size (tiny fairy, giant hand, doll-sized)
