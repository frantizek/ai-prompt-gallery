# Studio Spotlight Portrait Generator

Ultra-realistic cinematic fashion portraits under a single spotlight from a high top-down angle with satin textures and minimalist black background.

**Generator:** ChatGPT · **Status:** Active

---

## The Prompt

```
Ultra-realistic cinematic portrait under a single spotlight, high top-down angle. Identity preserved exactly from reference photo.

Teal-blue satin shirt over crisp white undershirt, tailored black trousers, white-blue sneakers. Soft diffused lighting, pure black background, dramatic gradient isolating the subject.

Top of frame: "POSTER CREATED BY FRANTIZEK" in minimal sans-serif. 8K, shallow depth of field, high-end fashion campaign elegance.
```

- Change the outfit (suit, dress, streetwear, formal)
