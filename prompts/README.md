## How to Use

1. Open a prompt folder
2. Read its `README.md`
3. Copy the prompt from `prompt.md`
4. Replace the main variable
5. Generate in your preferred AI tool

---

## Prompt Pack Standard

Each prompt folder in this repository is designed to follow a shared format:

- `README.md` — explanation and usage
- `prompt.md` — main copy-paste prompt
- `examples.md` — substitutions or variations
- `gallery.md` — generated examples
- `images/` — rendered outputs
